Hello there! Welcome to the Task-O-Matic! This is a task manager tracking app aimed at those who are neurodivergent and like to learn how to do tasks and not just be reminded of them! You can not only set tasks, but also, when it comes time to do them, find instructions on how to do them properly! No more worries about “Am I doing it right?” Enjoy your Task-O-Matic!

Main Menu

Task-O-Matic Main Menu

List of Options:

The Calendar: helps you by telling you exactly what day your assigned tasks need to be done by!

View Tasks will allow you to view, edit, delete, and confirm completion of current tasks!

Create or Edit Tasks will allow you to create and edit tasks for date, goal, description, and even the time!

Task Help is the instruction manual you wished you had been given at birth! You can find various tasks and links to simple instructions on how to do those tasks!
